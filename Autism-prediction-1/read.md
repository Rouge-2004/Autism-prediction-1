# 🧠 Autism Prediction using AI

---

## 🚀 Overview

This AI-based **Autism Prediction System** is designed to analyze user responses from a clinically validated screening questionnaire and predict the likelihood of Autism Spectrum Disorder (ASD).  
It utilizes **Machine Learning**, a simple and intuitive **Flask** web interface, and **XGBoost** to deliver fast, interpretable results.

---

## 🎯 Features

✅ **ASD Screening** – Predicts the likelihood of Autism based on survey responses  
✅ **Confidence Score** – Displays how confident the model is in its prediction  
✅ **Machine Learning Model** – Trained using XGBoost and Scikit-learn  
✅ **User-Friendly Web Interface** – Built with **Flask** for easy access and interaction  
✅ **Lightweight & Fast** – Simple design, quick inference, deployable on any platform  
✅ **Secure & Private** – No sensitive data is stored permanently

---

## 🧱 Tech Stack

🔹 **Machine Learning**: XGBoost, Scikit-learn  
🔹 **Backend**: Flask  
🔹 **Frontend**: HTML, CSS  
🔹 **Data Handling**: NumPy  
🔹 **Deployment**: Docker, Localhost
